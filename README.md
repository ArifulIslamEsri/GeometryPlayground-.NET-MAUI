# 🗺️ Geometry Playground (ArcGIS MAUI)

A simple interactive GIS mobile/desktop application built with **.NET MAUI** and **ArcGIS Maps SDK for .NET**.

This app allows users to interact with a map by adding, deleting, and drawing geometries in real time.

---

## 🚀 Features

- ✅ Add point by tapping on the map  
- ✅ Delete features by tapping existing graphics  
- ✅ Draw polylines (multiple vertices)  
- ✅ Draw polygons (area shapes)  
- ✅ Clear all graphics  
- ✅ Switch between modes easily  

---

## 🛠️ Built With

- .NET MAUI  
- ArcGIS Maps SDK for .NET  
- C#  

---

## 📱 How It Works

1. Select a mode (Add, Delete, Line, Polygon)  
2. Tap on the map  
3. Shapes are drawn dynamically  
4. Use "Finish" or "Clear" to reset
